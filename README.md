# 🎬 CineShow — Movie Ticket Booking Platform

CineShow is a movie ticket booking platform that provides a convenient way for users to explore movies, view showtimes, and book cinema tickets through a simple and user-friendly interface.

## ✨ Features

- 🎥 **Movie Browsing** — Explore available movies and view their details.
- 🕒 **Showtimes** — View movie show information and available timings.
- 🎟️ **Ticket Booking** — Book tickets for selected movie shows.
- 💳 **Demo Payments** — Experience the ticket booking process with demo payment functionality.
- 🔐 **User Authentication** — Register and log in to the platform.
- 🛠️ **Admin Panel** — Manage movie information and related details.

## 🛠️ Technology Stack

- Next.js
- React
- JavaScript
- CSS

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Code-Cool-2006/Avalanche-Task.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Avalanche-Task
   ```

3. Install the required dependencies in the relevant project directory.

4. Configure the required environment variables as described in the project setup.

5. Start the application using the appropriate development command.
